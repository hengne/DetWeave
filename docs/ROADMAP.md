# 开发路线与补充功能

这是一份产品路线，未实现项不代表当前应用能力。

| 阶段 | 工作 | 验收标准 |
|---|---|---|
| v0.1 基础闭环 | 多 API、文本抽取协议、带来源 IR、有限形状、SVG/三维、确定性导出 | 合成样例可下载、原生 Geant4 加载／检查，并显示验证边界 |
| v0.2 科研试用 | 真实模型基准、受控澄清修订、隔离 worker、DD4hep 回归、版本差异 | 用户文本到实际几何的独立人工参考对照；每项通过绑定模型哈希 |
| v0.3 参数化设计 | 安全表达式、参数依赖、旋转、二维晶体阵列、材料自定义 | 属性测试及跨后端位置／体积／材料核对，无静默损失 |
| v0.4 仿真扩展 | 敏感体、cell ID、读出、场、光学材料／表面、测试粒子源 | 指定用途的物理配置完整性与参考算例，而不只几何外形 |
| v1 集成 | GDML 导入、受限 DD4hep 工程接入、团队审核与集群 | 保留实验特有语义，更新可审阅、可回退、可复现 |

## 应补充的功能

1. **设计分支**：保留“20 层”和“16 层”备选，记录每个决策的原文和确认者。首版只有待澄清问题，尚无完整分支模型。
2. **量纲与总量约束**：解析表达式的安全 AST；例如 20×(1+5) mm 超过 100 mm 时，明确指出冲突，绝不自动削层。首版要求模型提出问题，尚无通用约束求解器。
3. **受控增量补丁**：对话修改产生 JSON patch 和影响范围；修订后旧验证失效，支持撤销及版本比较。
4. **材料预算与质量**：扣除子体替代体积，沿指定路径积分；单列密度来源、温压、辐射长度与计算近似。
5. **工程尺度问题**：间隙、贴合、数值精度、薄膜实体／光学表面、包覆和边界容差必须记录；不能通过增大容差自动消错。
6. **读出语义**：区分材料“硅”与敏感体，区分几何重复编号与实验 cell ID，检查编号位宽和唯一性。
7. **实际后端可视化**：从加载后的 ROOT/Geant4 几何生成第二份视图，与即时 IR 预览比对，定位导出偏差。
8. **评测与费用**：人工参考集含单位缺失、冲突、中英混合、轮次撤回、复杂布局；按数值、拓扑、无依据补全、澄清必要性、运行通过率评测。记录 token、价格版本及调用预算。
9. **既有工程导入**：先只导入已支持特征，遇到未知字段明确拒绝或保留为不可编辑内容，不生成貌似完整但缺语义的模型。
10. **参数扫描**：每个点都有不可变 IR 哈希、输出和验证；先排除非法点，再比较材料预算及模拟结果。
11. **本地／内部部署**：本地模型、服务商许可清单、输入脱敏、项目级访问控制、审计与密钥托管。
12. **可靠后台任务**：排队、取消、资源限制、失败分类、可恢复下载；提示注入与异常模型输出作为不可信数据处理。

## 第一轮真实试用建议

从一个小型采样量能器和一个晶体阵列开始，每个场景准备：明确描述、缺单位、尺寸冲突、
两个候选方案、多轮修改。先由研究者冻结参考 IR，再用同一语料测试账号实际可用的 GPT-4
或其他配置模型。不能用服务商模拟响应通过率代替抽取准确率。
