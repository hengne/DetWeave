# DetWeave v0.3.0 — Conversation-driven geometry / 对话式几何设计

**DRAFT — NOT RELEASED. Replace this status only after review, builds and validation.**
**发行说明草稿，尚未发行。审查、构建和验证完成后再更新状态。**

DetWeave 0.3.0 introduces continuous conversation around a saved detector geometry.
Ask questions, resolve unclear dimensions and request changes while reviewing the
current SVG/3D model. Geometry revisions retain parent links and parameter changes;
restoration and explicit user confirmations are saved with the project.

DetWeave 0.3.0 支持围绕当前探测器几何持续对话，在 SVG／3D 预览旁提问、澄清尺寸和
提出修改。几何版本记录父版本和参数变化，恢复历史版本与用户确认也保存在项目中。

Provider/model/API settings are remembered automatically in a separate local user
configuration file. This is permission-protected plaintext storage, not an encrypted
keychain. Keys do not enter project journals or geometry exports.

服务商、模型与 API 配置自动记忆，单独保存于本机用户配置文件。当前为权限保护的
明文保存，不是钥匙串加密；Key 不进入项目记录和几何导出。

Developers can run the full browser interface using a local Python backend without
compiling installers. Follow the bilingual README. The previously withdrawn
independent HTML/WASM download is not reinstated. PDF design reports are deferred.

开发者无需编译安装包，可通过本机 Python 后端直接调试网页界面，步骤见中英文 README。
此前撤下的独立 HTML/WASM 下载不恢复；PDF 设计报告仍待实现。
