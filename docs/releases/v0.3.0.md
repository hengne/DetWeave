# DetWeave v0.3.0 — Conversation-driven geometry / 对话式几何设计

DetWeave v0.3.0 adds continuous conversation, persistent geometry revisions and remembered model settings. English and Chinese interfaces and README demonstrations are included. This is a public preview; signing and platform-validation limits are listed below.

v0.3.0 新增持续对话、几何版本与模型配置记忆，包含中英文界面和更新后的真实操作演示。这是公开测试发行版，签名与平台验证范围见下文。

## Workflow / 使用方式

Create a named project and explicitly choose a storage location. Paste the first discussion, then continue with questions or changes in the left chat. Clarification and answer-only turns keep the current geometry. Changes create revisions with parent links and deterministic parameter differences. Restore a previous version to branch from it; stale confirmations are rejected instead of silently confirming changed values.

新建项目并明确选择保存位置，在左侧粘贴初始讨论，随后持续提问或修改。澄清和普通回答保留当前几何；修改产生记录父版本和参数差异的新版本。可恢复旧版继续设计；过期确认会被拒绝，避免确认了不同于原先看到的数值。

The right panel shows SVG/3D, geometry data and export tools. PDF design-report generation is deferred. Raw Thinking is hidden; concise status, elapsed time and cancellation remain. API settings auto-save per provider in a separate local user file. Storage is permission-protected plaintext, not keychain encryption. Keys and raw reasoning are excluded from project records/exports.

右侧显示 SVG／3D、几何数据和导出工具，PDF 设计报告暂未实现。主界面隐藏原始 Thinking，保留状态、耗时和停止。API 配置按服务商单独自动保存到本机用户文件；当前为权限保护的明文存储，不是钥匙串加密。Key 和原始思考不进入项目记录或导出。

## Developer web environment / 网页开发环境

No native build is needed for development. Install the Python project and run:

```sh
python -m detweave serve --dev-ui --open --port 0
```

Follow the [English README](https://github.com/hengne/DetWeave#run-the-developer-web-environment--no-native-compilation) or [中文 README](https://github.com/hengne/DetWeave/blob/main/README.zh-CN.md) for full Windows/macOS/Linux setup. This serves one HTML document from a local Python backend; Python calls providers directly. It is not the withdrawn independent `file://` HTML/WASM download, and no hosted relay is required.

开发无需编译安装包。按 README 安装 Python 项目后运行上述命令，通过本机网页调试；本机 Python 直接连接服务商，不需要在线转发服务。独立 `file://` HTML/WASM 下载不恢复。

## Validation / 验证

- 128 Python tests and browser conversation/settings regression passed. Review corrections include protocol null handling, explicit completion markers, sub-tolerance geometry limits, draft/revision synchronization, secret-echo checks and stale-confirmation protection.
- Live Volcengine `ark-code-latest` synthetic test: create a 5 mm silicon box, change only thickness to 8 mm, ask its current thickness without a new revision. All three turns passed; provider returned model ID `auto`, so the underlying routed model is unspecified.
- Fresh Geant4 11.1.3 GDML/C++ builds and runtime checks passed for sampling, beamline, nested and thin-world examples, including overlap rejection, navigation, geantino smoke and material lookup outside the build directory. These are geometry tests, not detector-response physics validation.
- DD4hep 1.28 generated plugin C++ compiled and linked. Full build/runtime validation remains blocked by a missing Boost library in the local installation; no runtime-success claim is made.
- Platform-native results and build commits are recorded in `BUILD-MANIFEST.json`. Android is build-verified only; iOS device signing and physical-device testing are not included.

128 项 Python 测试及浏览器回归通过，火山三轮真实合成几何对话通过。Geant4 样例完成重新编译与运行检查；DD4hep 插件编译链接通过，但完整运行验证受本机依赖缺失阻挡。各平台具体实测结果以构建清单为准，安卓与手机真机验证边界明确保留。

The original Argon fixed-mode suite gives 24 passes and one documented expectation disagreement: it expects an old revision ID to confirm newly edited geometry. DetWeave deliberately rejects that request; independent Python/browser tests verify edited values survive and confirmation works with the new revision. See [the review response](https://github.com/hengne/DetWeave/blob/main/docs/reviews/argon-v0.3.0-response.md).

原 Argon 验收套件为 24 项通过、1 项预期分歧：旧版本号不能用于确认已经修改的新几何。独立回归测试已验证修改值不会丢失，新版本可以正确确认。
