# 验证记录与边界

验证日期：2026-11-06。样例均为本仓库的合成几何，不含实验内部设计或会议记录。

## Python 与接口

50 项自动化测试通过：Schema、非法／非有限数值、重复 ID、层级循环、实例上限、
支持形状的重叠与越界、圆管内孔、触面、引文缺失、假设／推导阻止导出、确定性 ZIP、
文件哈希、XML 转义、DD4hep 导出、三种模型协议、截断响应拒绝、本机 HTTP 请求和跨源防护。

API 协议的本地模拟测试不衡量真实模型的理解准确率。真实模型小样本结果单独记录，
不能推断对任意会议记录、复杂几何或未见过的模型都可靠。

## Geant4 11.1.3 原生验证

执行脚本：`scripts/validate_backends.py`。结果见
[机器可读记录](verification/geant4-11.1.3.json)。

| 几何 | 实例数 | GDML 加载 | 直接 C++ | IR／实际几何比对 | 跟踪 |
|---|---:|---|---|---|---|
| 4 周期钨／硅 | 8 | 通过 | 通过 | 位置、材料、体积、密度一致 | 10 个 geantino 事件通过 |
| 圆管与硅片 | 2 | 通过 | 通过 | 同上，含圆管内孔 | 10 个 geantino 事件通过 |
| 母体／子体嵌套 | 2 | 通过 | 通过 | 同上，含局部／全局坐标 | 10 个 geantino 事件通过 |

每种格式对所有子放置调用 `CheckOverlaps(10000, 0, true, 10)`，随机种子 12345。
上述样例在此配置下未检测到重叠。三条中心轴导航检查未检测到异常。
在采样结构中故意把硅片移入钨片，原生检查返回失败，说明测试能发现该类错误。

跟踪示例只有 geantino 和 transportation，不含能量沉积、探测器响应、敏感体或读出。
中心轴导航用 1e-5 mm 越界微移，检查范围有限，可能漏掉偏轴或极薄结构。
一次无报错不能证明所有重叠和导航问题不存在。

本机以 Apple clang 编译，使用已安装的 Geant4 GDML/Xerces-C 库。
跟踪运行需要正确设置 Geant4 数据环境，至少包括本机用到的 `G4ENSDFSTATEDATA`；
初次遗漏这个变量的失败已修正，不能把配置失败当作几何失败。

## DD4hep 1.28：有环境限制的加载测试

实际构造器编译通过，采样样例加载出 8 个实例（加 world 与零偏移 assembly 共 10 节点）。
另一个独立嵌套／圆管样例通过 C++ 遍历核对材料、局部位置、父子关系和复制编号。

材料转换中的稀疏元素表问题已定位并修复：ROOT 6.30 的 `TGeoMixture` 用注册元素
数量检查原子序数。DD4hep 导出会加入未被任何材料引用的内部元素表条目，同时给真实元素
和同位素加名称前缀，避免与 ROOT 自带定义碰撞。材料引用仍指向原同位素组成。

本机 DD4hep 构建时与运行时 ROOT 分别为 6.30/06 和 6.30/04，运行仍报告 Cling
模块错误。上述结果只是有条件的加载与层级测试；尚未在版本匹配的干净环境完成
DD4hep 重叠／导航和 DDG4 物理等价验证。发布新环境支持前必须重跑。
DD4hep 转换可能不保留 GDML 的平均激发能、材料状态等全部属性，不能宣称与 Geant4
材料物理完全等价。所有用户生成的项目默认标记 DD4hep runtime `not_run`。

## 当前不能据此声称的能力

- 任意自然语言的正确解析、所有矛盾的识别或完整语义验证。
- 任意输入几何已经通过原生后端加载；历史样例通过不覆盖新输入。
- 旋转、布尔体、自定义材料、光学表面、敏感体、场、自动约束求解。
- 完整能量沉积、计分、电子学读出或实验物理响应。
- 已投入生产的多用户服务、在线隔离构建队列或集群资源管理。
